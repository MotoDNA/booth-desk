항목 설정 (이 부스 전용)

현장에서 누르는 버튼을 회사에 맞게 바꿉니다. 업종을 고르면 기본 버튼이 자동으로 채워지고, 이름만 고쳐 쓰면 됩니다.

한 줄에 하나씩 적어 주세요. 줄 순서가 곧 화면 순서이고, 줄을 지우면 버튼도 사라집니다.

특정 버튼을 눌렀을 때만 나타나는 입력칸입니다. 필요 없으면 첫 칸을 비워 두세요.

저장한 설정을 코드 한 줄로 복사해 직원에게 보내세요. 직원은 아래 칸에 붙여넣고 적용만 누르면 됩니다. (API 키는 들어 있지 않습니다)

자동 인식 (선택)

켜면 촬영 즉시 회사명과 이름이 자동으로 채워집니다. 키는 이 휴대폰에만 저장되며 어디로도 전송되지 않습니다.

켜는 방법 — 컴퓨터에서 console.anthropic.com 접속 → 왼쪽 API keys → Create Key → 생성된 sk-ant- 로 시작하는 문자열을 복사해 아래에 붙여넣고 키 연결 확인을 누르세요. 모델명은 비워 두면 알아서 맞는 것을 찾습니다.

직원용 설치 링크

키 연결이 끝난 뒤 이 버튼을 누르면 키가 담긴 링크가 만들어집니다. 직원이 그 링크를 한 번만 열면 자동 인식이 켜진 상태로 바로 사용할 수 있습니다.

이 링크를 아는 사람은 누구나 키를 쓸 수 있습니다. 함께 일하는 사람에게만 보내고, 전시가 끝나면 키를 삭제하세요.

스캔 보정

사진을 찍거나 불러오면 그림자와 조명 얼룩을 걷어내고 배경을 하얗게 펴서 스캔한 문서처럼 만듭니다. 글자가 또렷해지고 용량도 줄어듭니다. 촬영 화면에서 언제든 원본과 번갈아 볼 수 있습니다.

실시간 공유 (구글 시트)

연결하면 접수 기록이 자동으로 구글 시트에 올라가고, 다른 직원의 기록도 자동으로 내려받아 명부에 함께 표시됩니다. 인터넷이 끊겨도 폰에는 정상 저장되며, 연결되는 순간 밀린 기록이 알아서 올라갑니다.

사진은 올라가지 않습니다. 용량이 커서 폰에만 보관됩니다.

다른 담당자 기록 합치기

직원이 내보낸 CSV 파일을 불러오면 이 폰의 명부에 함께 표시되고, 담당자별로 나눠 볼 수 있습니다. 사진은 따로 관리되므로 글자 정보만 합쳐집니다. 같은 기록을 두 번 불러와도 중복되지 않습니다.
