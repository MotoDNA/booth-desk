# BOOTH DESK B2B — 서버 설치 안내

이 폴더의 파일들을 **고객사 본인의 구글 계정**에 설치합니다.
설치하면 이런 것이 켜집니다.

- 리드·회사·상담 이력·후속 일정이 구글 시트로 모입니다
- 여러 대의 휴대폰이 같은 명단을 함께 봅니다
- AI 기능이 켜집니다 (Claude API 키가 필요합니다)

**Claude API 키는 이 스크립트 안에만 저장됩니다.** 앱(HTML)에는 키가 들어가지
않으므로, 앱 파일을 남에게 줘도 키가 새지 않습니다.

---

## 1. 구글 시트 만들기

1. https://sheets.google.com 접속
2. **빈 스프레드시트** 클릭
3. 이름을 `BOOTH_DESK_DB` 로 바꿉니다 (왼쪽 위 "제목 없는 스프레드시트" 클릭)

## 2. Apps Script 열기

1. 방금 만든 시트에서 위 메뉴 **확장 프로그램 → Apps Script** 클릭
2. 새 탭이 열립니다. 왼쪽에 `코드.gs` 파일 하나가 보입니다

## 3. 파일 7개 붙여넣기

먼저 원래 있던 `코드.gs` 안의 내용을 **전부 지웁니다.**

그다음 아래 순서대로, 왼쪽 **파일 옆 `+` → 스크립트** 를 눌러 파일을 만들고
이 폴더의 같은 이름 파일 내용을 그대로 붙여넣습니다.

| 만들 파일 이름 | 붙여넣을 파일 |
|---|---|
| `코드.gs` (이미 있음) | `Code.gs` |
| `Config` | `Config.gs` |
| `Utils` | `Utils.gs` |
| `SheetService` | `SheetService.gs` |
| `SyncService` | `SyncService.gs` |
| `AIService` | `AIService.gs` |
| `ApiRouter` | `ApiRouter.gs` |

> 파일을 만들 때 이름 뒤에 `.gs`는 붙이지 않아도 구글이 알아서 붙입니다.

**디스크 모양 아이콘(저장)** 을 누릅니다.

## 4. 비밀값 두 개 넣기

1. 왼쪽 톱니바퀴 **프로젝트 설정** 클릭
2. 맨 아래 **스크립트 속성** → **스크립트 속성 추가**
3. 아래 두 개를 넣습니다

| 속성 이름 | 값 |
|---|---|
| `SHARED_TOKEN` | 아무도 모를 긴 문자열 (예: `bd-2026-x8f2k9qm3z`) |
| `ANTHROPIC_API_KEY` | `sk-ant-...` 로 시작하는 Claude API 키 |

`SHARED_TOKEN`은 나중에 앱 설정에 똑같이 입력해야 하니 **적어 두세요.**
AI를 안 쓸 거면 `ANTHROPIC_API_KEY`는 비워 둬도 됩니다 (동기화는 됩니다).

**저장**을 누릅니다.

## 5. 시트 만들기

1. 위쪽 함수 선택 칸에서 **setup** 을 고릅니다
2. **실행** 클릭
3. 처음이면 권한을 묻습니다 → **권한 검토** → 본인 계정 선택 →
   "이 앱은 확인되지 않았습니다" 화면이 나오면 **고급** → **(안전하지 않음)으로 이동** →
   **허용**

   > 이 경고는 "구글 심사를 안 받은 내 스크립트"라는 뜻입니다.
   > 본인이 만든 것이므로 정상입니다.

4. 시트 탭에 `Events` `Leads` `Companies` … 가 생겼는지 확인합니다

## 6. 배포하기

1. 오른쪽 위 **배포 → 새 배포**
2. 톱니바퀴 → **웹 앱**
3. 다음처럼 맞춥니다
   - 설명: `v1`
   - 다음 사용자로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포** 클릭
5. 나오는 **웹 앱 URL** 을 복사합니다 (`.../exec` 로 끝납니다)

> "모든 사용자"가 걱정될 수 있는데, 주소를 알아도 `SHARED_TOKEN` 없이는
> 아무 것도 못 합니다. 휴대폰이 구글 로그인 없이 접속해야 해서 필요한 설정입니다.

## 7. 앱에 연결하기

앱에서 **설정 → 서버 연결** 로 갑니다.

1. 위 칸에 6번에서 복사한 **웹 앱 URL** 붙여넣기
2. 아래 칸에 4번의 **SHARED_TOKEN** 입력
3. **연결 확인** → `연결됨 · v3.0 · AI 사용 가능` 이 나오면 성공
4. **지금 동기화** → 그동안 쌓인 기록이 시트로 올라갑니다

---

## 코드를 고친 뒤에는

Apps Script에서 코드를 수정하면 **배포 → 배포 관리 → 연필 아이콘 →
버전: 새 버전 → 배포** 를 해야 반영됩니다. 저장만으로는 바뀌지 않습니다.
URL은 그대로 유지됩니다.

## 자주 나오는 문제

| 증상 | 원인과 해결 |
|---|---|
| `UNAUTHORIZED` | 앱에 넣은 토큰과 스크립트 속성의 `SHARED_TOKEN`이 다릅니다 |
| `NOT_CONFIGURED` | 스크립트 속성에 `SHARED_TOKEN`을 안 넣었습니다 |
| `ANTHROPIC_API_KEY is not set` | AI를 쓰려면 키를 넣고 **새 버전으로 다시 배포** |
| HTML이 돌아옴 / 파싱 오류 | 배포 설정에서 "액세스: 모든 사용자"가 아닙니다 |
| `BUSY` | 다른 휴대폰이 동시에 동기화 중입니다. 잠시 후 자동 재시도됩니다 |

## 안전장치

- 방문객이 적은 글자가 시트에서 수식으로 실행되지 않도록 처리합니다
- 한 번에 하나의 기기만 쓰도록 잠금을 걸어 동시 저장 충돌을 막습니다
- 삭제는 행을 지우지 않고 `deleted` 표시만 남깁니다 (기록 보존)
- 앱은 프롬프트를 서버에 보낼 수 없습니다. AI 프롬프트는 서버 안에 있습니다
